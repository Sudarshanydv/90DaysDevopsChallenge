# 90DaysDevOpsChallenge

## AWS DevOps Learning Journey

I am starting my #90DaysDevOpsChallenge to improve my practical knowledge of AWS, DevOps, Cloud, CI/CD, Docker, Kubernetes, and Infrastructure as Code.

During this challenge, I will focus on learning concepts and implementing them through hands-on practice.

## Topics I Will Cover

### AWS

EC2, S3, IAM, VPC, RDS, ELB, Route 53, Lambda, ECR, EKS, CloudWatch

### DevOps

Git, GitHub, Jenkins, GitHub Actions, CI/CD, Linux, Bash

### Containers

Docker, Docker Compose, Kubernetes, Helm

### Infrastructure as Code

Terraform and CloudFormation

### Monitoring

Prometheus, Grafana, CloudWatch

## My Goal

The main goal of this 90-day challenge is to build strong practical skills and become more confident in real-world AWS and DevOps projects.

I will learn, practice, build projects, document my progress, and share my learning throughout the challenge.
